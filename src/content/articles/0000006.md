**版本：260815**  
**支持：Windows 控制台 游戏 存档**

## 1. 快速开始

### 使用方法
1. 将 `songlll.hpp` 复制到你的项目目录。
2. 在源代码中包含本头文件：
   ```cpp
   #include "songlll.hpp"
   ```
3. 编译时链接 `windows.lib` 和 `user32.lib`（通常默认已链接）。
4. 所有功能位于命名空间 `songlll` 中。

### 最小示例
```cpp
#include "songlll.hpp"

int main() {
    songlll::setColor(10, 0);  // 亮绿色
    songlll::write("Hello, world!\n");
    songlll::write("按任意键退出...");
    songlll::pause();
    return 0;
}
```

## 2. 宏定义

| 宏名 | 值 | 说明 |
|------|-----|------|
| `VERSION` | `260815` | 头文件版本号（格式：YYMMDD） |
| `DELAY_MS` | `0` | `write` 函数中每个字符输出的延迟毫秒数（设为 0 即最低延迟，仍有打字机效果） |

## 3. 命名空间 `songlll` 函数列表

### 3.1 逐字动画输出

#### `int write(const char* format, ...)`
**功能**：类似 `printf`，支持格式化输出。若 `DELAY_MS > 0`，每个字符输出后会停顿，形成打字机效果。  
**支持格式符**：`%d`, `%i`, `%u`, `%x`, `%X`, `%s`, `%c`, `%%`  
**返回**：输出的字符总数。

**示例**：
```cpp
songlll::write("Score: %d\n", 100);
songlll::write("玩家: %s, 等级: %d\n", "K-817416", lv);
```

---

### 3.2 颜色设置

#### `void setColor(int fontColor, int backColor)`
**功能**：设置控制台前景色和背景色。  
**参数**：`fontColor` 0~15，`backColor` 0~15

| 值 | 颜色 | 值 | 颜色 |
|----|------|----|------|
| 0 | 黑色 | 8 | 深灰色 |
| 1 | 蓝色 | 9 | 亮蓝色 |
| 2 | 绿色 | 10 | 亮绿色 |
| 3 | 浅绿色 | 11 | 亮青色 |
| 4 | 红色 | 12 | 亮红色 |
| 5 | 紫色 | 13 | 亮紫色 |
| 6 | 黄色 | 14 | 亮黄色 |
| 7 | 白色 | 15 | 亮白色 |

**示例**：
```cpp
songlll::setColor(14, 1); // 亮黄色字体，蓝色背景
```

---

### 3.3 光标操作

#### `void gotoxy(int x, int y)`
**功能**：移动光标到 `(x, y)`（左上角为 `(0,0)`）。

#### `void ClS()`
**功能**：清空控制台屏幕，光标归位。

#### `bool showCursor(bool visible)`
**功能**：显示或隐藏光标。`true` 显示，`false` 隐藏。

---

### 3.4 窗口信息与控制

#### `int getWidth()`
**返回**：控制台窗口宽度（字符列数）。

#### `int getHeight()`
**返回**：控制台窗口高度（字符行数）。

#### `void lockWindowSize(int cols, int rows)`
**功能**：锁定控制台窗口大小为指定行列，**禁用窗口缩放和最大化按钮**，同时消除滚动条。  
**参数**：`cols` – 列数（宽度），`rows` – 行数（高度）  
**注意**：该函数会同时修改屏幕缓冲区大小和窗口大小，使二者相等。

**示例**：
```cpp
songlll::lockWindowSize(80, 25); // 经典 80x25 终端
```

---

### 3.5 键盘输入

#### `bool press()`
**功能**：检测是否有键被按下（非阻塞）。  
**返回**：`true` 有键按下，`false` 无。

#### `int getky()`
**功能**：读取按键（**不**回显）。阻塞等待。  
**返回**：按键的 ASCII 码或扩展码（功能键需两次调用）。

#### `int getkey()`
**功能**：读取按键并**立即回显**到控制台。阻塞等待。  
**返回**：按键的 ASCII 码。

**示例**：
```cpp
if (songlll::press()) {
    int ch = songlll::getky();
    if (ch == 27) songlll::write("按下了 ESC\n");
}
```

---

### 3.6 时间与延时

#### `void delay(unsigned int ms)`
**功能**：休眠指定的毫秒数（`Sleep` 的封装）。

#### `unsigned long getTick()`
**功能**：获取系统自启动以来的毫秒数（`GetTickCount` 的封装）。  
**返回**：毫秒数。

---

### 3.7 音频

#### `void beep(int frequency, int durationMs)`
**功能**：通过 PC 扬声器发出蜂鸣声。  
**参数**：`frequency` – 频率（Hz），`durationMs` – 持续时间（毫秒）

**示例**：
```cpp
songlll::beep(1000, 200); // 1kHz 响 200ms
```

---

### 3.8 其他工具

#### `void setTitle(const char* title)`
**功能**：设置控制台窗口标题。

#### `void pause()`
**功能**：暂停程序，显示“按任意键继续...”（通过 `system("pause > nul")` 实现）。

#### `long long getRand(long long s, long long t)`
**功能**：生成 `[s, t]` 范围内的随机整数（均匀分布）。  
**参数**：`s` – 最小值，`t` – 最大值（包含）

#### `double getRand(double s, double t)`
**功能**：生成 `[s, t]` 范围内的随机浮点数（均匀分布）。  
**参数**：`s` – 最小值，`t` – 最大值

**示例**：
```cpp
int dice = songlll::getRand(1, 6);
double pi = songlll::getRand(3.14, 3.15);
```

## 4. 存档系统（SaveManager）

### 4.1 类概述

`SaveManager` 提供了一个**可存档变量注册表**，支持将任意数量的全局变量（基本类型或数组）序列化到二进制文件，并可完整恢复。

### 4.2 核心方法

#### `SaveManager(uint32_t ver = 1)`
**功能**：构造函数，`ver` 为存档版本号（用于版本兼容校验）。

#### `template<typename T> void registerVar(const std::string& name, T& var)`
**功能**：注册一个普通变量（基本类型：`int`, `float`, `double`, `bool`, `char` 等）。  
**参数**：`name` – 变量名称（仅用于调试/错误提示），`var` – 变量引用

#### `template<typename T, size_t N> void registerArray(const std::string& name, T (&arr)[N])`
**功能**：注册一个固定大小的 C 风格数组。  
**参数**：`name` – 数组名称，`arr` – 数组引用

#### `bool saveToFile(const std::string& path)`
**功能**：将所有已注册的变量序列化并保存到文件。  
**参数**：`path` – 文件路径  
**返回**：`true` 成功，`false` 失败

#### `bool loadFromFile(const std::string& path)`
**功能**：从文件读取数据，恢复到已注册的变量中。  
**参数**：`path` – 文件路径  
**返回**：`true` 成功，`false` 失败（文件不存在或格式不匹配）

#### `~SaveManager()`
**功能**：析构时自动释放内部资源。

### 4.3 使用示例

```cpp
#include "songlll.hpp"
using namespace std;

int score = 100, level = 1;
int inventory[10] = {0};

songlll::SaveManager g_saveManager(1);

void initSaveSystem() {
    g_saveManager.registerVar("score", score);
    g_saveManager.registerVar("level", level);
    g_saveManager.registerArray("inventory", inventory);
}

int main() {
    initSaveSystem();
    
    // 读档
    if (g_saveManager.loadFromFile("save.dat")) {
        songlll::write("读档成功！score=%d, level=%d\n", score, level);
    }
    
    // 修改数据
    score += 100;
    level++;
    
    // 存档
    g_saveManager.saveToFile("save.dat");
    return 0;
}
```

## 5. 注意事项

1. **Windows 专用**：本库依赖 `<windows.h>` 和 `<conio.h>`，仅适用于 Windows 平台。
2. **随机数种子**：使用 `getTick()` 自动初始化，无需手动 `srand`。
3. **DELAY_MS 性能**：`write` 函数每字符延迟 `DELAY_MS` 毫秒，输出大量文本时建议设为 `0`。
4. **光标恢复**：程序退出前建议调用 `showCursor(true)` 恢复光标显示。
5. **存档限制**：`SaveManager` 要求所有存档变量为**平凡可复制**（基本类型或数组），不支持 `std::string`、`vector` 等复杂类型（可自行扩展，做这个得特别累）。
6. **版本兼容**：修改全局变量结构后，应递增 `SaveManager` 构造函数中的版本号，否则旧档无法加载。
7. **窗口锁定**：调用 `lockWindowSize` 后窗口无法缩放，需重启程序恢复。注意只支持win10。win11可以改用兼容的控制台版本。

## 6. 完整示例（存档 + 数值编辑器）

```cpp
#include "songlll.hpp"
using namespace std;

int coin = 200, health = 100, maxhealth = 100;
int crystal[101] = {0};

songlll::SaveManager g_saveManager(1);

void initSaveSystem() {
    g_saveManager.registerVar("coin", coin);
    g_saveManager.registerVar("health", health);
    g_saveManager.registerVar("maxhealth", maxhealth);
    g_saveManager.registerArray("crystal", crystal);
}

void showStatus() {
    songlll::ClS();
    songlll::write("coin: %d, health: %d/%d\n", coin, health, maxhealth);
    songlll::write("crystal[1]: %d\n", crystal[1]);
    songlll::pause();
}

int main() {
    initSaveSystem();
    
    songlll::setTitle("游戏存档演示");
    songlll::lockWindowSize(50, 20);
    songlll::setColor(11, 0);
    songlll::showCursor(0);

    // 尝试读档
    if (g_saveManager.loadFromFile("save.dat")) {
        songlll::write("读档成功！\n");
    } else {
        songlll::write("新游戏，使用初始数据。\n");
    }
    songlll::pause();
    songlll::ClS();

    while (1) {
        songlll::write("1.查看状态 2.修改数值 3.存档 4.读档 5.退出\n");
        int opt; cin >> opt;
        switch (opt) {
            case 1: showStatus(); break;
            case 2:
                songlll::write("新 coin: "); cin >> coin;
                songlll::write("新 crystal[1]: "); cin >> crystal[1];
                break;
            case 3:
                if (g_saveManager.saveToFile("save.dat"))
                    songlll::write("存档成功！\n");
                songlll::pause();
                break;
            case 4:
                if (g_saveManager.loadFromFile("save.dat"))
                    songlll::write("读档成功！\n");
                songlll::pause();
                break;
            case 5:
                songlll::showCursor(1);
                return 0;
        }
        songlll::ClS();
    }
}
```
